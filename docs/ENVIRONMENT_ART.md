# Environment-responsive artwork

Atlas remains the source of regions, sequences and state sets, including multiple assets per sheet and measured logical pivots. No new Atlas schema. Hex World consumes optional wind capabilities on existing style and object bindings.

A style's vegetation.assets entry may be a legacy asset ID string, or {"manifest":"./pack/manifest.json","asset":"family.states","state":"calm"}. The same vegetation key in vegetation.wind may specify {"bend":0.45,"reference_speed_ft_s":20,"states":[{"min_speed_ft_s":8,"state":"wind"}]}. The referenced Atlas state_set must contain the named states. Static sprites can omit states and use bend alone. The top and side detail bindings remain static regions, not animated surfaces. Placed objects use the same optional wind response in visual.wind. Walking state takes precedence over wind state for a moving object; wind deformation still applies. Assets without capabilities remain unaffected.

World config.environment stores global wind and ordered local zones. Wind velocity is a horizontal world XY vector in feet per second, gust is normalized 0–1. A zone has ID, axial center, hex radius, inclusive support-level range and wind override. Last match wins; calm zones can model shelter. No airflow simulation or automatic wall shielding. Sustained wind speed selects states; continuous deterministic spatial/time gusts drive deformation. Visual time drives motion even when simulation is frozen. This is not physical force and cannot change authoritative world state.

Asset agents: author original transparent sheets with multiple measured regions; keep the logical canvas, root pivot [0.5,1], dimensions and scale matched across calm/wind frames. Use canonical sequence/state_set, not duplicated environmental animation schemas. For grass/reeds, static or hybrid is fine. For flags, cloth and canopy, author calm/wind sequences only if they look natural in both conditions. Use neutral lighting and no baked terrain. Provide exact pack ID, asset ID, state names and suggested bend strength/reference speed to the integrator. Do not invent code or new Atlas fields. Test with no wind, two opposite directions, gust, sheltered area and contact combined. The bundled meadow sequence reuses different procedural grass silhouettes solely to exercise state resolution; not an approved wind animation.

The renderer shares one raster per asset/state per loaded style. Animated instances currently share visual-clock phase; independent phase/rate, directional frames, layered composition, precipitation, temperature, water flow and environmental gameplay effects are future extensions, not implemented capabilities.

## Climate and per-material artwork
Use detail.materials.<material>.top/side for per-material static Atlas bindings and optional color_mode (grayscale, rgb_detail, albedo). The default detail top/side remain fallback. Full-color albedo textures are unprojected, seamless, no baked directional shadows; material tint is replaced at strength 1, terrain lighting still applies. All layers share repeat_ft and strength. For seasonal foliage use vegetation.seasonal.<spring|summer|autumn|winter>.<variant> = existing binding. Missing variants fall back to the base binding; matching seasonal sprites retain root pivot and logical dimensions. Seasonal overrides take precedence over base artwork, retain the existing procedural wind bend by default, and may declare their own optional wind capability (including state thresholds) inside the seasonal binding. Do not inherit base state names across unrelated Atlas assets. No automatic weather-driven accumulation. The fixture seasonal swaps reuse existing grass silhouettes, not actual seasonal artwork.
