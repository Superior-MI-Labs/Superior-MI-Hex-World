# Foundation contract (v0.5)
This independent repository supersedes the height-only Tabletop prototype direction, not its existing implementation. Reference: https://github.com/Superior-MI-Labs/Interactive-Tabletop/blob/agent/hex-world-terrain-elevation-and-world-contract-20261125/HEX_WORLD_CONTRACT.md . Retain axial math and fixed 35.264 degree isometric projection with six yaw directions. Unlike the prototype, all ordinary interiors, caves and buildings share Q/R/Z; portals only for intentionally separate spaces.

## Authority
World configuration: smi-hex-world/1. Horizontal nearest-neighbor distance defaults to 5 ft, vertical step defaults to 5 ft, chunk defaults to 16 per axis. Signed integer addresses use floor division. Physical positions are derived, never camera pixels. Immutable grid per world; migration is explicit. A sparse known chunk has a default material and explicit overrides; absence of a chunk means unknown, not air. World.snapshot/restore implements sparse JSON saves (smi-hex-save/1), not streaming or durable indexed storage. Default cells and overrides remain authoritative. The lab exports terrain only, not clocks, effects or UI state. No gameplay bounds, but JS safe-integer arithmetic constrains representable addresses.

Geometry is a fixed triangulated hex fan: six corners counterclockwise from +30 degrees, center last; triangle i is center, i, (i+1)%6. A cell stores one solid interval between two seven-integer arrays, lower and upper, with 0 <= lower[i] <= upper[i] <= grid.geometry_subdivisions. Supported world profile: exactly 2 subdivisions (0, 2.5, 5 ft at default scale). Pure geometry functions retain parameterized subdivision math for future profiles. Four-slice experimental saves are rejected rather than silently rounded. Full, slab, ramp, peak and excavation are presets, not separate types. Equal lower/upper means zero volume. Multiple disjoint solid intervals and arbitrary geometry within one cell remain future work. Air must have zero solid volume. v0.1 shape kinds are intentionally replaced before persistent worlds exist; no silent migration. The mesh and surface sampler use the same fan. Edge i neighbors axial offsets [0,1],[-1,1],[-1,0],[0,-1],[1,-1],[1,0]; the opposite edge reverses endpoint order. Matching heights can be welded; differing profiles need exposed-face clipping. v0.3 adds explicit atomic connected corner edits (same Z, up to three solid cells; known air skipped, unknown rejected), independent edits, exact horizontal edge interval subtraction, and vertical shared-cap suppression. There is no permanent vertex welding: cliffs are intentionally supported. Unknown neighbors suppress boundary faces until known. The mesh can contain T-junctions; watertight indexed topology is a future gate; GPU depth buffering is implemented. WebGL2 lab previews 19 columns across five vertical levels using depth-tested terrain and alpha-cutout upright sprites. CPU triangle picking uses the same projection and interpolated depth. Canvas overlay is editor guides and debug fire only; no production translucent blending or collision. Presets affect only the selected cell. The subdivision selector is removed. A cell may contain air plus effects; surface state is stored in components.surface and saved with terrain. Excavation clears surface state when volume disappears.

## Time
Host advances simulation explicitly (manual, turn-based, real-time or scaled); frozen ignores advances. Visual animation uses an independent clock, optionally paused by host. Effects: persistent, decorative, timed, reactive. Reactive effects need registered material response rules; no generic automatic fuel/spread in v0.1. Timed effects expire in simulation time, never animation time. Explicit editing remains possible during frozen time. No implicit wall-clock mutation.

## Assets
Atlas owns artwork, pivots, region/sequence/state_set/composition definitions in smi-visual-pack/1. Hex World owns physical placement and state. Providers return validated native pack metadata through a shared resolver, not executable code. v0.4 adds HTTP pack loading, safe relative texture URLs, sprite-subgraph validation, decoded texture size checks and canonical Atlas renderer reuse for region/sequence/state_set. Composition, collection ZIPs, full schema validation, license policy enforcement, cache and integrity verification remain open. Native Atlas renderer is vendored verbatim from a pinned commit; it rasterizes transparent animation frames for GPU billboards. The pinned CC0 tutorial character is a reproducible fixture, not production artwork. Do not claim arbitrary third-party compatibility. A world-specific binding references stable pack/asset IDs and may map physical states to visuals. Prefer world-space surface textures and transparent overlays, anchored vertical sprites, and depth-aware geometry. Use Atlas animation timing rather than a competing format.

## Materials and surface state (v0.5)
The data-only smi-hex-materials/1 catalog defines substrate colors, vegetation compatibility, weighted variants and demonstration burn duration. Physical substrate remains independent of grass, moisture, leaves, snow and scorch. Surface components are validated and persisted. The world ID and address deterministically select a weighted variant. Renderer uses world-space procedural masks for surface coverage and transparent upright grass tuft sprites anchored to exposed triangles. These are debug assets, not published Atlas terrain assets; no parallel animation format. Reactive fire explicitly consumes grass and leaves, reduces health and snow, and increases scorch only when simulation advances. Persistent/timed visual flames remain independent debug overlays and are not saved. Reactive fire state survives terrain export. No fire spread, regrowth, climate model, true translucent blending or chunk mesh caching yet. The sample catalog is a proof of contracts, not a physical simulation. Unknown materials use a diagnostic color.
